# سيرفر الربط بين Streamer.bot والموقع

فكرة المشروع: Streamer.bot يتصل بهذا السيرفر كـ **WebSocket Client** (اتصال صادر منه)، فما تحتاج IP ثابت ولا ngrok ولا Port Forwarding. السيرفر هذا يكون مستضاف أونلاين، وموقعك (الداشبورد) يتصل فيه أيضًا ليستقبل نفس البيانات لحظيًا.

```
Streamer.bot (جهاز الستريمر) --[يتصل صادر]--> سيرفرك (مستضاف أونلاين) --[يبث]--> موقعك/داشبوردك
```

## 1. التشغيل محليًا للتجربة

```bash
cd streamerbot-server
npm install
npm start
```

بيطلعلك: `السيرفر شغال على البورت 8080`

افتح `dashboard-example.html` بالمتصفح، لازم يطلع "تم الاتصال بالسيرفر ✅".

## 2. الاستضافة أونلاين (عشان يصير عندك رابط ثابت دائم)

اختر أي منصة مجانية أو رخيصة تدعم WebSocket (يفضّل تجنب استضافات static فقط):

- **Render.com** (Web Service, مجاني للبداية)
- **Railway.app**
- **Fly.io**

الخطوات بشكل عام (تشابه في أغلبها):
1. ارفع هذا المجلد لـ GitHub repo
2. اربطه بالمنصة (Render/Railway) وسوي "New Web Service"
3. Build Command: `npm install`
4. Start Command: `npm start`
5. بعد النشر بتاخذ رابط زي: `https://your-app.onrender.com`
6. رابط الـ WebSocket يصير: `wss://your-app.onrender.com`

## 3. إعداد Streamer.bot (خطوات لصاحب البوت)

1. افتح Streamer.bot
2. روح لتبويب **Servers/Clients**
3. اختر **WebSocket Client** (مو Server)
4. حط الرابط: `wss://your-app.onrender.com`
5. فعّل الاتصال (Enable/Connect)
6. من إعدادات الأحداث (Events)، فعّل الأحداث اللي تبي ترسلها (Follow, Sub, Bits, Raid...) وتأكد إنها تُرسل كـ WebSocket Broadcast

> ملاحظة: شكل رسائل JSON اللي يرسلها Streamer.bot لكل حدث قد يختلف حسب إصداره وإعداداته. لما توصلك أول رسالة حقيقية، افتح الـ Console (`console.log` موجود بالكود) وشوف شكلها بالضبط، وبعدها عدّل دالة `mergeState()` في `server.js` عشان تطلع منها البيانات اللي تحتاجها فعليًا (اسم اليوزر، نوع الحدث، عدد البتس...).

## 4. ربطه بموقعك الفعلي (بدل ملف dashboard-example.html)

انسخ نفس منطق الاتصال من `dashboard-example.html` وحطه بملف JS بتاع موقعك (LEX Games / S3eeD / أي مشروع). كل ما توصل رسالة `type: 'event'`، حدّث الستريك/اللفل/البتس في الواجهة حسب البيانات.

## 5. نقاط مهمة

- استخدم `wss://` مو `ws://` بعد ما يصير موقعك على HTTPS (المتصفح يرفض ws:// من صفحة https://)
- لو تبي تربط أكثر من قناة/بوت بنفس السيرفر، تقدر تضيف معرف (channel id) وقت التسجيل وتفصل البيانات حسبه
- السيرفر الحالي يحتفظ بآخر حالة بالذاكرة فقط (تختفي لو أعاد التشغيل) — لو تبي تخزين دائم اربطه بـ Firebase زي باقي مشاريعك
